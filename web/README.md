# JobSeeker — Frontend

React 19 · TypeScript · Vite · Tailwind CSS v4

Proxies `/api/*` to the FastAPI backend on `:8000`.

## Commands

```bash
npm install
npm run dev       # dev server on :5173
npm run build     # production build → dist/
npm test          # vitest
npm run lint      # eslint
```

See the [root README](../README.md) for full setup and project docs.
